# Marsa Atlas — أطلس مرسى

## Problem Statement

كيف نساعد فرق المنظمات والباحثين والصحفيين على الانتقال من سؤال عن الهجرة أو اللجوء في مصر إلى مصدر موثوق وخدمة مناسبة وجهة ومسار إحالة، دون إخفاء حدود البيانات أو تاريخ التحقق؟

## Recommended Direction

Marsa Atlas هو طبقة معلومات عربية موثقة المصدر للخدمات والقانون والجهات والبيانات المرتبطة بالهجرة واللجوء في مصر. يخدم MCP وREST والويب من طبقة تطبيق واحدة، بينما يظل WordPress نظام التحرير والمراجعة والنشر.

الإصدار الأول للقراءة العامة. أداة `suggest_update` تنشئ اقتراحًا للمراجعة البشرية ولا تعدل السجل المنشور مباشرة.

## Key Assumptions to Validate

- [ ] الباحثون وفرق الإحالة يحتاجون إلى مصدر وخدمة وجهة في مسار بحث واحد.
- [ ] نموذج بيانات Marsa Core يوفر الحقول اللازمة لبداية مفيدة.
- [ ] إظهار تاريخ التحقق وحدود التغطية يزيد الثقة والاستخدام الفعلي.
- [ ] الجهات ستستخدم مسار اقتراح التحديث بدل إرسال تصحيحات غير منظمة.

## MVP Scope

- بحث موحد في الخدمات والجهات والقانون والمؤشرات والمصادر.
- اكتشاف الخدمات حسب الاحتياج والموقع والأهلية والجهة.
- سياق قانوني مرتبط بالمصدر وتاريخ المراجعة.
- brief بحثي أو إحالة يحمل citations وتحذيرات.
- REST API وMCP Streamable HTTP وstdio.
- موصل WordPress للقراءة، وبيانات Demo للاختبار والتطوير.

## Not Doing

- لا تخزين لبيانات الحالات أو المستفيدين.
- لا قرار نهائي بالأهلية ولا استشارة قانونية.
- لا تعديل مباشر للسجلات المنشورة بواسطة AI.
- لا دول خارج مصر في الإصدار الأول.
- لا forecasting للهجرة.
- لا نسخ للكود من ERX أو Humanitarian MCP.

## Success

- يصبح Atlas واجهة البيانات الرسمية لـMarsa.
- يعمل من MCP وREST بعقود متطابقة.
- كل نتيجة تحمل مصدرًا وتاريخ تحقق وحالة سجل.
- نشره كحزمة عامة وإتاحته لعملاء MCP.
