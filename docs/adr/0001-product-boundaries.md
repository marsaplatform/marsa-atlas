# ADR 0001: Product boundaries

## Status

Accepted — 2026-08-14

## Decision

- WordPress/Marsa Core هو نظام التحرير والمراجعة.
- Marsa Atlas هو نظام الاسترجاع والتفسير والتوزيع.
- طبقة التطبيق مستقلة عن MCP وREST.
- كل عمليات القراءة عامة، وأي تحديث يمر بمراجعة بشرية.
- مصر هي النطاق التحريري الأول، مع وجود `countryCode` في العقود.

## Consequences

- يمكن تغيير النقل أو المخزن دون تغيير أدوات المنتج.
- لا تعتمد اختبارات المجال على WordPress أو الشبكة.
- لا تصبح طبقة MCP مصدر حقيقة منفصلًا.
